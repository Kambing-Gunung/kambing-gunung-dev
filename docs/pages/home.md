# Home Page

Version: 1.0.0

Status: Frozen

---

# Overview

Home merupakan halaman utama dari Kambing Gunung Developer Platform.

Halaman ini menjadi pintu masuk utama bagi seluruh pengunjung untuk mengenal identitas Kambing Gunung, memahami filosofi di baliknya, melihat karya terbaik, dan memulai perjalanan menjelajahi website.

Home tidak bertujuan menampilkan seluruh informasi yang dimiliki website.

Sebaliknya, Home dirancang sebagai sebuah pengalaman (experience) yang memperkenalkan brand, membangun rasa penasaran, dan mengarahkan pengunjung menuju halaman-halaman berikutnya.

---

# Goals

Home memiliki tujuan sebagai berikut.

- Memberikan first impression yang kuat.
- Memperkenalkan identitas Kambing Gunung.
- Memperlihatkan kualitas engineering melalui karya.
- Membangun rasa penasaran terhadap developer di balik brand.
- Mengarahkan pengunjung menuju halaman lain.
- Menyampaikan pengalaman yang konsisten dengan identitas visual website.

---

# Target Audience

Home ditujukan untuk pengunjung yang ingin mengenal Kambing Gunung dan developer di baliknya.

Target utama meliputi:

- Recruiter
- HR
- Software Engineer
- Developer
- Game Developer
- Calon Client
- Pengunjung umum

---

# Design Principles

Seluruh Home Page mengikuti prinsip berikut.

## Story Driven

Home dibangun sebagai sebuah perjalanan.

Setiap section memiliki tujuan yang jelas dan saling terhubung.

Pengunjung tidak hanya membaca informasi, tetapi mengalami sebuah alur cerita.

---

## Brand First

Home memperkenalkan brand terlebih dahulu sebelum memperkenalkan developer.

Kambing Gunung merupakan identitas utama website.

Developer diperkenalkan secara bertahap melalui perjalanan pengguna.

---

## Minimal but Meaningful

Setiap informasi yang ditampilkan harus memiliki tujuan.

Tidak seluruh informasi harus ditampilkan pada Home.

Informasi yang lebih detail disediakan pada halaman lain.

---

## Progressive Disclosure

Informasi disampaikan secara bertahap.

Setiap section hanya menjawab satu pertanyaan utama.

Informasi berikutnya diberikan setelah pengguna melanjutkan eksplorasi.

Pendekatan ini bertujuan membangun rasa penasaran, menjaga fokus pengguna, dan menciptakan pengalaman membaca yang lebih alami.

---

## Consistency

Seluruh section mengikuti Design System yang telah dibuat.

Typography.

Color.

Spacing.

Motion.

Layout.

Komponen.

---

## Reusable

Seluruh section dibangun menggunakan Layout Components dan UI Components yang telah tersedia.

Tidak membuat komponen baru apabila kebutuhan sudah dapat dipenuhi oleh komponen yang ada.

---

## Desktop First

Phase ini berfokus pada pengalaman Desktop.

Responsive akan dikembangkan pada Phase berikutnya.

# Implementation Guidelines

Seluruh section menggunakan Layout Components yang telah tersedia.

Container digunakan sebagai pembatas lebar konten.

Section digunakan sebagai pembatas vertikal.

Grid digunakan hanya apabila section membutuhkan lebih dari satu kolom.

Stack digunakan sebagai layout utama untuk penyusunan konten secara vertikal.

Seluruh styling mengikuti Design System.

Tidak diperbolehkan membuat nilai spacing, typography, radius, maupun color di luar Design Tokens.

Animasi tidak menjadi prioritas pada implementasi awal (Phase 5).

# Project Representation

Project ditampilkan sebagai paper/poster yang ditempel pada quest board.

Setiap project paper berfungsi sebagai representasi visual dari project
dan dapat berinteraksi dengan pengguna.

Featured Projects hanya menampilkan project yang paling representatif

# Hover Behavior

Ketika pengguna melakukan hover pada sebuah project paper:

-   Project paper mendapatkan subtle glow.
-   Project paper dapat mengalami sedikit scale/lift.
-   Description Panel muncul di samping board.
-   Description Panel menampilkan informasi singkat mengenai project.
-   Project lainnya tetap berada pada posisi normal.

Hover interaction harus tetap subtle agar tidak mengganggu komposisi
utama board.

---

# Click Behavior

Ketika pengguna melakukan click pada project:

-   Project Detail Panel muncul di atas board.
-   Detail project menjadi fokus utama.
-   Informasi project dapat ditampilkan lebih lengkap.
-   Board tetap menjadi konteks visual di belakang detail.

Detail panel tidak dimaksudkan untuk menggantikan halaman Projects.

Pengguna tetap dapat membuka halaman Projects untuk memperoleh informasi
lengkap mengenai seluruh project.

# Visual Structure

Featured Projects menggunakan dua layer utama untuk membangun depth dan
parallax.

``` text
Featured Projects
│
├── Layer 1 — Background
│   ├── Sky
│   └── Distant City
│
└── Layer 2 — Foreground
    ├── Board
    ├── Project Papers
    ├── Description Panel
    ├── View All Projects Sign
    ├── Wall
    └── Ground / Road
```

---

# Parallax

Featured Projects menggunakan parallax sederhana yang hanya terdiri dari
dua layer.

## Layer 1 --- Background

Berisi:

-   Sky
-   Stars
-   Distant City

Layer ini bergerak lebih jauh ketika pengguna menggerakkan cursor.

Tujuannya memberikan kesan depth pada environment.

---

## Layer 2 --- Foreground

Berisi:

-   Quest Board
-   Project Papers
-   Description Panel
-   View All Projects Sign
-   Wall
-   Ground / Road

Layer ini bergerak sangat sedikit dibandingkan background.

Tujuannya menjaga board sebagai anchor utama section.

---

## Parallax Principle

Parallax harus bersifat subtle.

Konsep pergerakan:

``` text
Cursor Movement
       ↓

Sky + City
    ←────────→
      ± lebih jauh

Board + Environment
       ←→
     ± sedikit
```

Contoh nilai awal untuk implementation:

``` text
Background : ±12px
Foreground : ±3px
```

Nilai tersebut bukan nilai final dan dapat disesuaikan ketika
implementation dan responsive testing dilakukan.

Parallax tidak boleh membuat board terasa bergeser secara berlebihan.

---

# Layer Relationship

Sky + City berfungsi sebagai deep background.

Board dan seluruh environment foreground diperlakukan sebagai satu
kesatuan visual.

Project Papers, Description Panel, dan View All Projects Sign mengikuti
foreground layer.

Tidak ada parallax tambahan pada masing-masing object tersebut.

Tujuannya menjaga visual tetap konsisten dan menghindari efek gimmick
yang berlebihan.

# Responsive Behavior

Pada desktop, parallax dan interaction dapat digunakan secara penuh.

Pada perangkat dengan pointer terbatas atau touch device:

-   Hover interaction tidak menjadi requirement utama.
-   Project tetap dapat diakses melalui click/tap.
-   Parallax dapat dikurangi atau dinonaktifkan.
-   Layout harus tetap dapat digunakan tanpa bergantung pada motion.

Komposisi board harus tetap menjadi fokus utama pada berbagai ukuran
layar.

---

# Accessibility

Interaction tidak boleh hanya bergantung pada hover.

Project harus tetap dapat diakses menggunakan:

-   Keyboard focus.
-   Click.
-   Tap.

Informasi penting tidak boleh hanya tersedia melalui visual glow atau
parallax.

Motion harus bersifat dekoratif dan tidak menjadi bagian wajib dari
pemahaman content.

Jika `prefers-reduced-motion` aktif, parallax dan motion interaction
harus dikurangi atau dinonaktifkan.
