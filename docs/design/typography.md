# Typography

> Typography defines the visual hierarchy and readability across the Kambing Gunung Design System.
>
> The goal is to create a calm, modern, and developer-focused reading experience.

---

# Font Family

## Primary

Used for all UI components and body content.

```css
font-family:
    "Inter",
    "Segoe UI",
    sans-serif;
```

---

## Monospace

Used for code snippets, terminal output, and technical information.

```css
font-family:
    "JetBrains Mono",
    monospace;
```

# Type Scale

| Token | Size | Weight | Line Height | Usage |
|--------|-----:|--------:|------------:|------|
| Display | 48px | 700 | 120% | Hero title |
| Heading 1 | 36px | 700 | 120% | Page title |
| Heading 2 | 30px | 600 | 130% | Section title |
| Heading 3 | 24px | 600 | 130% | Card title |
| Heading 4 | 20px | 600 | 140% | Small section |
| Body Large | 18px | 400 | 170% | Intro paragraph |
| Body | 16px | 400 | 170% | Default content |
| Body Small | 14px | 400 | 160% | Secondary content |
| Caption | 12px | 400 | 150% | Labels, helper text |
| Overline | 11px | 600 | 150% | Small uppercase labels |
