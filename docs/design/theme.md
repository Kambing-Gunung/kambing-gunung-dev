# Product Statement

Kambing Gunung is a Personal Developer Platform that combines software engineering, storytelling, and interactive web experiences into a single place.

---

# Theme

> The visual identity and design philosophy of the Kambing Gunung Developer Platform.

---

# Vision

Kambing Gunung is more than a portfolio website.

It is a personal developer platform that tells the story of a software engineer's journey through a peaceful world inspired by mountains, pixel art, anime atmosphere, and modern web technology.

The experience should feel calm, immersive, and memorable rather than flashy or overwhelming.

---

# Design Goal

The website should:

- Introduce the developer.
- Showcase projects and technical skills.
- Tell a personal journey.
- Feel like exploring a peaceful world.
- Remain professional and easy to navigate.

---

# Emotional Composition

The visual atmosphere follows four emotional pillars.

| Emotion | Weight |
|----------|--------|
| Peaceful | 30% |
| Adventure | 30% |
| Mystical | 20% |
| Modern | 20% |

Every design decision should support at least one of these emotions.

---

# Inspirations

The project takes inspiration from the atmosphere and storytelling of:

- Tokyo Night (mood only)
- Frieren
- Makoto Shinkai
- Pixel Art
- Mountain Landscape

These inspirations are references, not templates to copy.

The goal is to create a unique identity rather than imitate existing works.

---

# Storytelling

The website represents a journey.

As the user scrolls deeper, the world slowly transitions from twilight into night.

The transition should feel subtle enough that users may not immediately notice it.

The world does not become darker to create tension.

Instead, it becomes calmer.

Scrolling should feel like continuing a peaceful adventure.

---

# Design Principles

## 1. Calm Before Adventure

Every page should invite exploration through a peaceful atmosphere.

The design should never feel loud or overwhelming.

---

## 2. Pixel with Elegance

Pixel art is part of the identity.

However, it should be used as an accent rather than dominating the interface.

Modern UI and readability always come first.

---

## 3. Developer First

The platform exists to present software engineering work.

Design should support the content instead of competing with it.

Information should always remain easy to find and comfortable to read.

---

## 4. Motion Has Purpose

Animations should communicate meaning.

Motion is used to reinforce interaction, improve navigation, and strengthen storytelling.

Animations should never exist purely for decoration.

---

## 5. Reusable Everything

Every visual decision should be reusable.

Colors, spacing, typography, shadows, animations, and components should all be designed as reusable design tokens and UI components.

---

# Visual Direction

The visual identity should balance four characteristics:

- Peaceful
- Elegant
- Playful
- Professional

The interface should feel suitable for both creative audiences and technical recruiters.

---

# Theme Philosophy

The platform is not simply a collection of web pages.

It is a journey.

Every section should feel like another step into the world.

Every animation should have meaning.

Every color should support the atmosphere.

Every component should be reusable.

Build like an engineer.

Design like a storyteller.
