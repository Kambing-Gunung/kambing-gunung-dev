# Shadow

> Shadows are used to create depth, not decoration.

---

# Shadow Scale

## Shadow SM

```css
0 2px 4px rgba(0,0,0,.12)
```

---

## Shadow MD

```css
0 8px 20px rgba(0,0,0,.18)
```

---

## Shadow LG

```css
0 16px 40px rgba(0,0,0,.22)
```

---

## Shadow XL

```css
0 24px 64px rgba(0,0,0,.28)
```

---

# Usage

| Component | Shadow |
|-----------|--------|
| Button Hover | SM |
| Card | MD |
| Floating Panel | LG |
| Modal | XL |
