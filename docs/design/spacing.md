# Spacing

> Spacing defines consistent distances between elements throughout the Kambing Gunung Design System.
>
> A consistent spacing system improves readability, alignment, and scalability.

---

# Base Unit

The design system uses a **4px spacing scale**.

```
1 Unit = 4px
```

All spacing should be multiples of **4** whenever possible.

---

# Spacing Scale

| Token | Value | Usage |
|--------|------:|------|
| Space 1 | 4px | Tiny gap |
| Space 2 | 8px | Icon spacing |
| Space 3 | 12px | Small spacing |
| Space 4 | 16px | Default spacing |
| Space 5 | 20px | Medium spacing |
| Space 6 | 24px | Card padding |
| Space 8 | 32px | Section spacing |
| Space 10 | 40px | Large spacing |
| Space 12 | 48px | Hero spacing |
| Space 16 | 64px | Large section spacing |
| Space 20 | 80px | Major separation |
| Space 24 | 96px | Page spacing |
